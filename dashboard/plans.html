一、怎么判定"出事了"(侦测判据,全部自动)

运保部稽查组 + 各级上级同时盯,判据写死,不靠人猜。
判据阈值谁发现立即动作
员工卡死同一节点 15 分钟无"提交"组长(盯进度表)+稽查组查日志定位;判卡死的,走"员工预案"
员工离线会话无响应 / 心跳缺失 30 秒稽查组(秒级)标记离线;重派同任务;走"员工预案"
员工空转前台 sleep / 无产出空转 5 分钟稽查组中断空转;强制后台化;记违规一次
组长离线/卡死心跳缺失 2 拍(20 分钟)经理 + 稽查组经理代管本组;走"组长预案"
经理离线/卡死心跳缺失 2 拍(20 分钟)厂长 + 稽查组厂长代管该部门;启用备用经理席
厂长离线/卡死心跳缺失 1 拍(30 分钟)运保部经理(红灯)+稽查组备用厂长席接手;走"厂长预案"
审计/质检占线待审/待验收队列 >30 分钟未动稽查组本部门经理接力审/验(闸不跳过,只换人)
产出不合格审计驳回 / 质检不过审计 / 质检打回上家(策划/生产),计驳回次数
额度耗尽当日额度使用 >90%稽查组切备用模型;高耗任务排队延后;余量留给交付
平台级异常心跳全停 / 会话丢失 / 库损坏稽查组 + 运维走"平台预案"(见第四节)

二、通用替补阶梯(任何岗位倒下,按这条链顶上)

原则:任务不等人——原人不行,下一级立刻顶上;永远回到主线继续,不问发起人。
第 1 步 · 重试本人
重建会话 / 重投任务(断点续做);同一人最多 2 次。
第 2 步 · 同组替补
员工挂 → 同组替补员工接(每组建制:组长+3 员工,剩 2 人轮值)。
第 3 步 · 上级顶上
员工全挂 → 组长亲自做;组长挂 → 经理代管;经理挂 → 厂长代管部门。
第 4 步 · 备用席/降级
厂长挂 → 预设备用厂长席接管;仍不可行 → 降级交付 + 补偿池,结论写交付单。

三、逐人预案(每个岗位 × 每种故障的具体处置)

"谁发现 → 60 秒内做什么 → 替补从哪来 → 什么情况升级 → 留痕"。升级只在内部分级,不问发起人。
岗位故障处置动作(按序)替补来源升级去向(内部)
厂长离线/会话中断①稽查组红灯;②备用厂长席立即接管(预建,MD 卡与队列原样挂接);③在制任务继续跑;④运保经理监督交接;⑤交付单注明"代管期间"备用厂长席(常备)—(最高)
厂长判定卡住(两拍不推进)①稽查组报红灯;②备用厂长席先批当前计划;③原厂长恢复后交接复核备用厂长席—
策划经理离线①厂长代管策划部;②启用备用经理席;③当前计划由计划组长维持滚动计划组长 / 备用经理席厂长
策划组长离线/卡死①经理代管本组;②组内任务分给员工继续;③计划板标"组务代管"部门经理策划经理
策划员工卡死(15 分钟无提交)①组长查日志;②重派同任务给本组替补员工;③仍不行组长亲自做;④记违规一次;⑤复盘写经验库同组替补员工 → 组长策划组长
审计经理离线①厂长代管审计部;②审核队列由组长接力;③独立闸不跳过,只换人审计组长 / 备用经理席厂长
审计组长离线/卡死①经理接力审;②积压超 30 分钟强制分单给审计员工审计经理审计经理
审计员工卡死/离线①组长接手该方案;②重派给其他审计员工;③驳回结论必须留理由与标准条款审计同组 → 组长审计组长
生产经理离线①厂长代管生产部;②三组组长各自维持组内产线;③关键卡由质检降级验生产组长 / 备用经理席厂长
生产组长离线/卡死①经理代管本组;②本组在制任务分给组内 3 员工均摊;③组内员工全忙 → 借调他组生产经理 / 借调生产经理
生产员工卡死(节点 15 分钟无提交)①组长查日志判"卡死";②任务原样重派同组替补员工(最多 3 次);③3 次失败 → 组长亲自做;④仍失败 → 经理顶上;⑤全程秒级留痕,复盘入经验库同组替补 → 组长 → 经理生产组长
生产员工离线(会话丢失)①稽查组 30 秒判离线;②同任务重派替补员工(断点续做,MD 卡带上下文);③原员工恢复后不重复做,只做校核同组替补员工生产组长
质检经理离线①厂长代管质检部;②验收队列由组长接力;③独立闸不跳过,只换人质检组长 / 备用经理席厂长
质检组长离线/卡死①经理接力验;②积压 >30 分钟分单给质检员工;③验收标准逐条打勾,不许整批过质检经理质检经理
质检员工卡死/离线①组长接手验收;②重派他人;③结论必须附条款编号与证据路径质检同组 → 组长质检组长
运保经理离线①厂长直接接管稽查;②稽查组自动按规则执行不等人;③效率分析批处理照常由脚本产出稽查组长 / 厂长厂长
稽查员工离线①稽查组长补位;②黄灯规则由脚本兜底(心跳缺失自动标黄);③恢复后回查离线期日志稽查同组 → 组长运保经理
效率分析组批处理失败①脚本自动重试 2 次;②仍失败 → 产出"部分日报"并标缺口;③次日第一批发补算重跑脚本运保经理
审计/质检闸被压/被催放水①独立闸结论不受部门经理干预;②稽查组查"非标准通过";③发现放水 → 该批验收作废重验,记违规—厂长

四、秒级剧本(三个真实场景怎么跑)

剧本 A:生产员工"卡死"
  1. T+0员工 A 接到子任务,开始做(留痕"开始")
  2. T+15m同一节点无"提交" → 组长进度表标黄 + 稽查组同步告警
  3. T+16m组长查日志:会话无响应 → 判"卡死",任务标"重派中"
  4. T+18m同任务重派给同组替补员工 B(带 MD 卡上下文,断点续做)
  5. T+45mB 提交 → 质检照常;A 记违规 1 次,复盘写经验库(下次先查 A 的卡点类型)
  6. 上限若 B 也卡:重派 C(共 3 次)→ 组长亲自做 → 经理顶上;任何一档都不问发起人
剧本 B:经理/组长"离线"
  1. T+0经理心跳缺失(两拍=20 分钟)→ 稽查组红灯报厂长
  2. T+1m厂长宣布"代管该部门",启用备用经理席;组长照常领活
  3. T+5m审核/生产/验收队列不动 → 组长接力分单,闸不跳过只换人
  4. T+恢复原经理回来:交接复核,一分钟内确认"代管期结论有效"
  5. 留痕全程 MD 卡记"代管开始/结束",效率分析计一次"人力中断"
剧本 C:厂长"离线"(单点也要有预案)
  1. T+0厂长心跳缺失一拍(30 分钟)→ 运保经理红灯 + 稽查组双确认
  2. T+1m预建"备用厂长席"立即接管:接 MD 卡队列、批当前计划、发布闸照跑
  3. T+全场在制任务不停;新需求进"待厂长复核"队列(只排队,不问发起人)
  4. T+恢复原厂长回归 → 十分钟交接:复核代管期决策,接受的直接过,有疑的当场改判
  5. 留痕交付单注明"含代管期";效率分析出"单点中断"事件
剧本 D:平台级故障(调度停摆/会话丢失/库损坏)
  1. T+0全心跳停 → 稽查脚本判"平台级";自动跑健康检查(权限/占用/悬挂 run 六项)
  2. T+2m按检查结果自愈:清死占用/悬挂 run;重启会话;必要时重启应用(令牌注入,不丢数据目录)
  3. T+5m积压队列自动补跑(按原定顺序);断点从 MD 卡续做
  4. T+10m出"中断复盘":停摆起止、影响单量、补偿项(≤3)入改善层
  5. 兜底库损坏 → 从每日备份恢复(最近一次备份点),丢的节点重跑,MD 卡不丢历史
